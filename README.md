- Building **serverless applications on AWS**: Lambda + API Gateway with SAM, Cognito auth, a React frontend, all in a pnpm + Turborepo monorepo shipped through Azure Pipelines.
- Maintaining **REST APIs in Node.js / TypeScript** backed by MySQL, with JWT auth, structured logging (Pino), and OpenAPI/Swagger docs.
- Running a **self-hosted container stack** (Docker, Traefik with local TLS, Portainer) that showcases distributed-systems setups with RabbitMQ, Redis, Postgres, MySQL, Jenkins and Prometheus + Grafana
